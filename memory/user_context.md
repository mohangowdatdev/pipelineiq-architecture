User is building an enterprise-grade Azure data pipeline system (PipelineIQ) for the first time at this architectural scale. They want thorough explanations: what each component does, why it's separate, how it connects to the next thing, and what goes wrong if it doesn't exist. They are not a beginner — they understand code — but they want the reasoning made explicit, not assumed.

They are working in a learning-by-building mode: the architecture is planned in detail (PLANNING.md, SCHEMA.md, DECISIONS.md) and they want the implementation to closely follow the plan with each decision made explicit.
